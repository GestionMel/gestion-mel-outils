Créer le baromètre de votre clinique
Vos employés répondront sur leur téléphone, avec un lien ou un code QR. Leurs réponses sont anonymes : vous verrez seulement les résultats de l'équipe, chaque trimestre, à partir de 3 réponses.
Lien du sondage pour vos employés
Comment le partager :
• Envoyez le lien dans le groupe de messagerie de l'équipe, ou
• Imprimez l'affiche avec le code QR et placez-la dans la salle des employés.

Notre conseil : lancez le baromètre une fois par trimestre, par exemple pendant les deux premières semaines de janvier, avril, juillet et octobre. Les résultats d'un trimestre s'affichent à partir de 3 réponses, pour protéger l'anonymat.

Sondages remplis sur papier? Ouvrez le sondage avec le bouton « Voir le sondage » et saisissez chaque copie, une à la fois.
